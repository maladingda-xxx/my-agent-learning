  一、Python 异步编程（建议先学）

  学习重点： async/await、asyncio.run()、协程概念、为什么异步 ≠ 多线程。这个项目里用的就是 async def + await 模式，不难。

  二、FastAPI（核心框架）

  官方文档：
  - https://fastapi.tiangolo.com/zh/ — 有完整的中文翻译，文档质量极高，直接跟着 Tutorial 走一遍就够了

  学习重点：
  - 路由定义（@app.get/post/delete）
  - Pydantic 模型（BaseModel）做请求/响应校验
  - Depends 依赖注入
  - 错误处理（HTTPException）

  ---
  三、Pydantic v2

  官方文档：
  - https://docs.pydantic.dev/latest/
  - https://docs.pydantic.dev/latest/concepts/pydantic_settings/ — 本项目用它管理 .env 配置

  学习重点： BaseModel、Field 校验器、pydantic-settings 的 BaseSettings 从 .env 文件自动加载配置。

  ---
  四、OpenAI Python SDK

  官方文档：
  - https://github.com/openai/openai-python
  - https://platform.openai.com/docs/api-reference/chat — Chat Completion API 参考

  学习重点： AsyncOpenAI 客户端创建、chat.completions.create() 方法、消息格式 [{role, content}]。DeepSeek 完全兼容这个接口，学会一个等于两个都会。

  推荐资源：
  - https://api-docs.deepseek.com/zh-cn/ — 本项目实际用的是 DeepSeek

  - https://python.langchain.com/docs/introduction/ — 后续扩展会用到的 Agent 框架

  学习重点： 理解 role 体系（system/user/assistant）、temperature 的含义、多轮对话如何拼接 messages。
